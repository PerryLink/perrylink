**上游** —— 995 个已合并 PR，分布在 115 个不属于我的仓库里，从 AWS、Apple、Docker、Microsoft、NVIDIA、Prometheus、Redis、Tencent 与 vLLM 项目，到一个人的小项目都有。995 个之中，**961 个在 112 个仓库的默认分支上留下了 commit；另有 3 个仓库共 34 个合并没有留下 commit**，合计 115 个仓库。那三个是 `SihanTeng/awesome-deepseek-harness-plugins`（32 个合并）、`Tencent/MMKV`（1）与 `Anil-matcha/open-genjutsu`（1）。**插件生态** —— 126 个在维护的 Apache-2.0 插件：安全、工作流、研究、消息桥接、开发者体验；2026-10-08 起加上 53 项核查器合规套件与九个更新的合规工具；27 个业务工具于 2026-11-03 组成 task-first 插件市场：其中六个并入 finance/contract suite，其余是专业工具（发票、银行、合同、质量、报关、物流、HR、零售、建筑、PDF 表格、模型参数），一个是安装伴侣、一个是评测工具。**翻译相关命名于 2026-11-08 拆分：** `dsh-param-repair`（1.0.2）是原先叫 `dsh-translate` 的供应商参数映射 + 确定性 JSON 修复插件，而 `dsh-translate`（0.3.5）现在是全页翻译器，跑会话自己的模型路由，代码、路径、命令与产品名原样保留。**时间证据（2026-11-09）：** `dsh-sherlock` 0.5.0 是 catalog-only 的本地工作台，处理公开来源时间线与日期冲突 —— 五个时钟、TEG、T-S-C-E、查询账本、diff/verify/review，以及一份自包含 HTML 报告；它不建站、不找人、也不给真/假结论。**27 个领域工具都在 0.1–0.2、没有 alpha 标记**；多数 README 明确标注 not-GA，我们跑过的每个首次运行都收进一个 pack，五个场景 pack 把它们首尾串起来。旧的 `dsh-eval-harness` 已改名为 `dsh-eval-pack`。公开目录是 **[perrylink.github.io](https://perrylink.github.io/)** —— 插件索引下 185 个页面（站点 sitemap 除根之外列出 115 个 URL），全部直接写在服务端 HTML 里、不靠 JavaScript 渲染，因此从搜索结果点进来的读者看到的是正文，而不是加载中状态。

## 🪦 已退役与冻结

两个不同的决定，共同点是不再维护一份重复实现。

**已退役 —— 官方 harness 吸收了这项能力。** 三个插件停止，因为 harness 现在原生提供同样的能力 —— [dsh-background-agents](https://github.com/PerryLink/dsh-background-agents)（原生可续跑子代理）、[dsh-session-pin](https://github.com/PerryLink/dsh-session-pin)（内置会话置顶）与 [dsh-team-rooms](https://github.com/PerryLink/dsh-team-rooms)（Agent Teams，实验性/opt-in）。

**已冻结 —— 功能开发停止。** 八个自研行被冻结：`dsh-autotier`、`dsh-budget`、`dsh-cert-mcp`（仅参考）、`dsh-claude-move`、`dsh-community-bench`、`dsh-defend`、`dsh-draw` 与 `dsh-reach`。第三方的 `pan17/dsh-wechat` 是另一回事，请看它自己的上游状态。我们自己的行停止兼容更新，已安装的继续可用，也不再维护第二套实现。这是基于实测的采用决定，不是质量判决。

## 🌍 插件发布在哪里

- **GitHub**（本主页）、**[Gitee](https://gitee.com/perrylink)**、**[GitCode](https://gitcode.com/PerryLink)** 与 **npm** —— 源码、CI 与发布都在这里；两个镜像现在都带全部在维护的仓库（默认分支与 tag），中国大陆读者不用代理就能浏览或 clone。`perrylink` npm 账号持有 **190 个包名和 2,422 个版本**（registry 查询 `maintainer:perrylink`，2026-11-12）；其中 **140** 个至少有一个版本带 SLSA 来源证明，**69** 个当前 `latest` 带，**50** 个完全没有。
- **npm 下载量** —— **截至 2026-11-11 的 30 天内 382,430 次**（3 个最新包名还没有 30 天序列，所以这是下限）。[dshfind](https://dshfind.com/plugins?q=PerryLink) 把生态仓库列进 sitemap，并为其中 **9 个**发布下载徽章 —— 三个 10k+、两个 5k+、两个 2k+、一个 1k+、一个 500+ —— 合计 **45,500+**。徽章是取整档位，所以这是地板不是总和。
- **DSH Desktop Market** —— 在 Market → Sources 里添加 `https://cdn.jsdelivr.net/gh/PerryLink/dsh-family-catalog@main/deploy/artifacts/v1/plugins.json`，就能在应用内浏览整个生态（**152 个包，目录生成于 2026-11-11**）。同一次构建还暴露一个 stdio MCP server（`plugin_search` / `plugin_get`），数据来自中文 discovery 索引。目录包含 2026-11-08 发布的 **24 个包科研套件**、2026-11-10 新增的五个包（catalog-only，不进安装名册），以及改用途的 `dsh-translate` 全页翻译器。
- **MCP Registry** —— 四个 server，全部通过 GitHub OIDC 从各自的发布工作流发布：`dsh-cert-mcp`（🧊 已冻结，仅参考）、`dsh-customs-mcp`、`jevcore-mcp` 与 `laya-mcp`。
- **GitHub Actions** —— [dsh-github](https://github.com/PerryLink/dsh-github) 与 [dsh-test-drive](https://github.com/PerryLink/dsh-test-drive) 还提供 composite action，因此可以按 `uses: PerryLink/dsh-test-drive@vX` 安装。
- **第三方目录** —— 十几个 DSH 列表和索引会抓取 [`dsh-plugin` topic](https://github.com/topics/dsh-plugin)；旗舰 dsh-auto-review 带一张 [OpenSSF Scorecard](https://api.securityscorecards.dev/projects/github.com/PerryLink/dsh-auto-review)。
