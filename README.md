I fix other people's projects, I maintain a plugin family for
[DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness), and I run
[Phocinae](https://github.com/Phocinae), my typed-decision model lab. Independent open-source developer in
Beijing — not affiliated with DeepSeek, and not a DeepSeek employee.

**Upstream** — 509 merged pull requests in 102 repositories that are not mine, from AWS, Apple, Docker,
Microsoft, NVIDIA, Prometheus, Redis, Tencent and the vLLM project down to one-person projects. **The
family** — 126 actively maintained Apache-2.0 plugins: security, workflows, research,
messaging bridges, developer experience, since 2026-10-08 a 53-checker compliance suite plus nine newer
compliance tools, and 27 business tools that became a task-first plugin market on 2026-11-03: six feed the
finance/contract suites, the rest are specialist tools (invoicing, banking, contracts, quality, customs,
logistics, HR, retail, construction, PDF tables, model parameters), one is an install companion and one is an
eval utility. **All 27 are non-alpha since 2026-11-03**, each with a runnable first run, and five scenario packs
chain them end to end. The old `dsh-eval-harness` is archived in favor of `dsh-eval-pack`. The public catalogue is
**[perrylink.github.io](https://perrylink.github.io/)** — 185 pages under the plugin index (the checker tree keeps its own 114-entry sitemap), complete in the served
HTML with no JavaScript rendering them, so a reader who arrives from a search result sees the text rather
than a loading state.

I also contribute to **[Cordis](https://github.com/cordiverse/cordis)**, the plugin kernel DeepSeek Harness
vendors as `@deepseek-ai/cordis` — nine merged pull requests there, from async-generator cleanup to reload
behaviour.

## 🪦 Retired & frozen

Two different decisions, both about not maintaining a duplicate.

**Retired — the official harness absorbed the capability.** Three plugins stopped because the harness now
ships the same capability natively — [dsh-background-agents](https://github.com/PerryLink/dsh-background-agents)
(native continuable subagents), [dsh-session-pin](https://github.com/PerryLink/dsh-session-pin) (built-in
session pinning) and [dsh-team-rooms](https://github.com/PerryLink/dsh-team-rooms) (Agent Teams, experimental/opt-in).

**Frozen — the ecosystem converged on a more widely adopted implementation.** Five plugins — `dsh-budget`,
`dsh-draw`, `dsh-claude-move`, `dsh-reach` and `dsh-defend` — plus the third-party `dsh-wechat` row stopped
feature work because a more widely adopted implementation is the mainstream choice for that capability.
This is a measured adoption call, not a quality verdict; the repos that carry a maintenance-status section record the comparison.

Either way, the operational meaning is the same: compatibility updates stop, existing installs keep
working, and no second implementation is maintained.
