<sub>“Certified” is our own family attestation, not an independent audit or a DeepSeek endorsement. Counters without a date of their own were re-measured on 2026-11-12.</sub>

I fix other people's projects, I maintain a plugin family for
[DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness), and I run
[Phocinae](https://github.com/Phocinae), my typed-decision model lab. Independent open-source developer in
Beijing — not affiliated with DeepSeek, and not a DeepSeek employee.

**Upstream** — 684 merged pull requests in 111 repositories that are not mine, from AWS, Apple, Docker,
Microsoft, NVIDIA, Prometheus, Redis, Tencent and the vLLM project down to one-person projects. Of the
684, **650 left a commit on the default branch in 108 credited repositories; 34 merges in 3 repositories
credit no commit**, giving 111 repositories in total. Those three are
`SihanTeng/awesome-deepseek-harness-plugins` (32 merges), `Tencent/MMKV` (1) and
`Anil-matcha/open-genjutsu` (1). **The family** — 126 actively maintained Apache-2.0 plugins: security, workflows, research,
messaging bridges, developer experience, since 2026-10-08 a 53-checker compliance suite plus nine newer
compliance tools, and 27 business tools that became a task-first plugin market on 2026-11-03: six feed the
finance/contract suites, the rest are specialist tools (invoicing, banking, contracts, quality, customs,
logistics, HR, retail, construction, PDF tables, model parameters), one is an install companion and one is an
eval utility. **The translation name was split on 2026-11-08:** `dsh-param-repair` (1.0.2) is the vendor-parameter
mapping + deterministic JSON repair plugin formerly called `dsh-translate`, and `dsh-translate` (0.3.5) is now a
full-page translator that runs on the session's own model route and keeps code, paths, commands and product
names verbatim. **Temporal evidence (2026-11-09):** `dsh-sherlock` 0.5.0 is a catalog-only local workbench
for public-source timelines and date conflicts — five clocks, TEG, T-S-C-E, query ledger, diff/verify/review,
and a self-contained HTML report. It does not build a site, search for people, or issue a true/false verdict. **The 27 domain tools are at 0.1–0.2 with no alpha tag**; most are explicitly marked not-GA in their
READMEs, and each first run we exercised is captured in a pack, with five scenario packs chaining them end
to end. The old `dsh-eval-harness` was renamed to `dsh-eval-pack`. The public catalogue is
**[perrylink.github.io](https://perrylink.github.io/)** — 185 pages under the plugin index (the site sitemap lists 114 URLs besides the root), complete in the served
HTML with no JavaScript rendering them, so a reader who arrives from a search result sees the text rather
than a loading state.

I also contribute to **[Cordis](https://github.com/cordiverse/cordis)**, the plugin kernel DeepSeek Harness
vendors as `@deepseek-ai/cordis` — nine merged pull requests there, from async-generator cleanup to reload
behaviour.

## 🪦 Retired & frozen

Two different decisions, both about not maintaining a duplicate.

**Retired — the official harness absorbed the capability.** Three plugins stopped because the harness now
ships the same capability natively — [dsh-background-agents](https://github.com/PerryLink/dsh-background-agents)
(native continuable subagents), [dsh-session-pin](https://github.com/PerryLink/dsh-session-pin) (built-in
session pinning) and [dsh-team-rooms](https://github.com/PerryLink/dsh-team-rooms) (Agent Teams, experimental/opt-in).

**Frozen — feature work stopped.** Eight first-party rows are frozen: `dsh-autotier`, `dsh-budget`,
`dsh-cert-mcp` (reference only), `dsh-claude-move`, `dsh-community-bench`, `dsh-defend`, `dsh-draw` and
`dsh-reach`. The third-party `pan17/dsh-wechat` is separate; check its upstream status. For our own rows,
compatibility updates stop, existing installs keep working, and we do not maintain a second implementation.
This is a measured adoption call, not a quality verdict.
